# TrigoLab · Trigonometría 4º ESO

App web para aprender, practicar y jugar con la trigonometría de 4º de la ESO: razones trigonométricas, ángulos notables, relaciones fundamentales, circunferencia goniométrica, reducción al primer cuadrante, radianes y problemas.

Versión 1.0 · https://indalo-apps.github.io/trigonometria/
