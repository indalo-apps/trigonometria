# TrigoLab · Trigonometría 4º ESO

© 2026 **Adela Moreno Vega** y **Carlos Moreno Otto**. Todos los derechos reservados (ver [LICENSE](LICENSE)).

App para aprender, practicar y jugar con la trigonometría de 4º de la ESO: razones trigonométricas, ángulos notables, relaciones fundamentales, circunferencia goniométrica, reducción al primer cuadrante, radianes y problemas. Se puede instalar en el móvil y funciona sin conexión.

Se publica con GitHub Pages: https://indalo-apps.github.io/trigonometria/

Para sacar una versión nueva: subir el número en `<meta name="app-version">` (index.html) y en `CACHE` (sw.js), y añadir sus novedades en `NOVEDADES`. Los móviles que la tengan abierta se actualizan solos, sin cortar un juego ni un ejercicio a medias.
